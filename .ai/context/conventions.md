# Conventions

Les fichiers TypeScript observés utilisent :

- des apostrophes simples pour les chaînes ;
- pas de point-virgule en fin de ligne ;
- l'indentation par deux espaces ;
- des fonctions et variables nommées en anglais ;
- le mode TypeScript strict avec `noUnusedLocals`, `noUnusedParameters` et `noImplicitReturns`.

Les fichiers de configuration existants suivent le style JSON ou TypeScript attendu par leurs outils. Conserver ce style dans les nouveaux changements.
