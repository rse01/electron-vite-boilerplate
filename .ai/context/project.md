# Projet

Ce dépôt est un boilerplate simple pour une application de bureau Electron.

## Technologie

- Electron pour l'application de bureau.
- Vite pour le développement et le build.
- TypeScript pour le code.
- `vite-plugin-electron` pour intégrer Electron à Vite.

## Lancer le projet

Après `npm install` :

```sh
npm run dev
```

Les autres scripts déclarés sont `npm run build` pour compiler et empaqueter l'application, et `npm run preview` pour prévisualiser le build Vite.
