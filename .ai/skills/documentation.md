# Skill : documentation

Pour documenter le projet :

1. Vérifier l'information dans les fichiers du dépôt.
2. Écrire des explications courtes, concrètes et destinées au lecteur visé.
3. Utiliser les noms et commandes réellement présents dans le projet.
4. Marquer `TODO: à compléter` quand une information manque.
5. Relire les liens, chemins et exemples après modification.

Ne pas présenter une supposition comme un fait.
