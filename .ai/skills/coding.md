# Skill : coding

Pour modifier le code :

1. Comprendre la demande et lire le code existant concerné.
2. Faire un petit plan des fichiers à modifier.
3. Implémenter la solution la plus simple qui suit l'architecture actuelle.
4. Tester le changement avec les commandes disponibles.
5. Expliquer les fichiers modifiés et les vérifications effectuées.

Ne pas élargir la modification à des fichiers sans rapport.
