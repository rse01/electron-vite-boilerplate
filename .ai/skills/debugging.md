# Skill : debugging

Pour trouver un problème :

1. Reproduire le problème avec une étape claire.
2. Observer les erreurs et localiser le code concerné.
3. Formuler une cause probable avant de modifier le code.
4. Faire le plus petit correctif possible.
5. Reproduire le problème et vérifier qu'il est corrigé.

Ne pas masquer une erreur ni corriger des symptômes sans comprendre la cause.
