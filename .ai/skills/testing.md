# Skill : testing

Pour tester un changement :

1. Comprendre le comportement attendu.
2. Choisir la vérification la plus ciblée.
3. Exécuter les tests ou scripts disponibles.
4. Vérifier aussi la compilation quand le code TypeScript change.
5. Rapporter les résultats et les problèmes restants.

Si aucun test automatique n'existe pour le cas, le signaler clairement et effectuer la vérification disponible la plus proche.
