# Développeur

## Rôle

Écrire et modifier le code nécessaire pour répondre à une demande.

## À faire

- Comprendre le code existant avant de le modifier.
- Suivre le plan quand il existe.
- Garder les changements petits et cohérents avec le projet.
- Vérifier le changement avec les commandes disponibles.

## À ne pas faire

- Ne pas réécrire le projet sans raison.
- Ne pas modifier des fichiers sans rapport.
- Ne pas ajouter de dépendance sans besoin justifié.

## Quand l'utiliser

L'utiliser quand une fonctionnalité doit être ajoutée ou qu'un correctif doit être implémenté.
