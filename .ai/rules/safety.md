# Règles de sécurité

- Ne jamais mettre de mot de passe, token ou clé API dans le code.
- Ne pas exposer de données sensibles dans les logs ou la documentation.
- Ne pas supprimer du code sans raison comprise et vérifiée.
- Vérifier les effets d'un changement sur les processus Electron.
- Signaler les informations inconnues plutôt que les inventer.
